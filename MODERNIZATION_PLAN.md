# Wowser Next Modernization Plan

## Phase 1: Baseline modernization

Goals:

- Establish a modern development baseline.
- Do not change WoW resource formats or gameplay behavior.
- Prepare gradual migration.

Planned:

- Vite migration
- TypeScript incremental adoption
- Modern dependency audit
- Build reproducibility
- Test baseline

Later phases:

- WebGL2 renderer modernization
- Worker architecture
- Asset cache
- Protocol worker
- KTX2/Basis texture pipeline
- WASM hot paths
